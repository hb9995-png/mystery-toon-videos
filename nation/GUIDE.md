# 나랏돈사용설명서 (@nation.moneys) 제작 가이드

소상공인·중소기업 사장님에게 정책자금·정부지원금 정보를 쉽게 정리해 주는 1080x1350 캐러셀(6~8장). 마지막 장은 프로필 링크(무료 확인 신청 폼)로 유도한다.

## 도구
- `python3 nation/tools/cards.py <episode.json> <outdir>` → outdir/01.jpg ... (JPEG, 4:5).
- 카드 종류: cover(tag,title,sub), warn(num,quote,fact,note), info(num,title,body,note), list(title,items[[제목,설명],...] 3~4개), todo(title,items 3개), cta(title,sub,button,foot).
- 마지막 장은 항상 기존 에피소드와 같은 cta 를 쓴다(버튼 "프로필 링크 → 무료 확인").
- 예시: nation/tools/episodes/ep01~ep05.json. 렌더링 후 직접 열어 글자 잘림을 고친다(info 본문 5줄, 한 줄 16자 안팎).

## 내용 규칙 (중요)
- 정보 계정이다. "대출 받아드립니다", "승인 보장", "무조건", "100%", "최저금리", "누구나 가능", "대행" 같은 표현을 쓰지 않는다. 대출 중개처럼 보이는 문구 금지.
- 숫자·금리·한도·마감일·자격은 그날 WebSearch/WebFetch 로 공식 자료(중소벤처기업부, 소상공인시장진흥공단 semas.or.kr, 중진공 kosmes.or.kr, 기업마당 bizinfo.go.kr, 신용보증재단, 정부24)에서 실제로 확인한 것만 쓰고 sources.txt 에 링크를 남긴다. 확인 못 하면 숫자 없이 쓴다.
- 주제 예: 이번 달 공고·마감 임박 자금, 자금 종류별 설명, 신청 절차, 준비 서류, 거절 이유, 브로커 주의(제3자 부당개입), 지자체 지원금, 용어 풀이, 자주 묻는 질문. 시의성 있는 공고 주제를 우선한다.
- 특정 컨설팅 업체·금융사 이름 홍보 금지. 정치적 평가 금지.
