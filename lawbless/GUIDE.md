# 법블레스유 (@law.bless.you) 제작 가이드

생활법률 카드뉴스 릴스. 카드 6~7장 슬라이드 영상, 음성 없음, 오리지널 배경음악. 하루 2편(점심 a, 저녁 b).
나중에 법률사무소 광고를 받을 계정이므로 정확성이 최우선이다.

## 주제
- 20~40대가 실제로 겪는 일: 알바·직장(임금, 퇴직금, 해고, 연차), 전월세(보증금, 수리, 계약갱신), 중고거래·온라인 사기, 층간소음, 교통사고, 명예훼손·모욕, 이혼·상속 기초, 소비자 환불 등. used.txt 와 겹치지 않게. 같은 날 두 편은 분야를 다르게.
- 표지 질문은 "~해도 될까?", "~면 처벌될까?" 처럼 궁금하게.

## 사실 확인 (필수)
- 모든 숫자·조문·판례는 이번 실행에서 WebSearch/WebFetch 로 실제로 연 자료(국가법령정보센터, 법원, 정부 부처, 대한법률구조공단, 법률 매체·변호사 칼럼 2곳 이상 일치)에서만 쓴다. 확인 못 한 숫자나 판례 번호는 빼고 쓴다.
- 금액은 그해 기준을 다시 확인(최저임금 등). 법정형은 조문 그대로.
- "무조건", "100%", "반드시 이긴다" 같은 단정 금지. 특정 법률사무소·변호사 이름 금지.

## 만들기
- `tools/episodes/epNN_<영문슬러그>.json` (형식은 tools/cards.py 맨 위). cards 4~5장, 장마다 body 2~4줄, law 에 근거 조문. seed 는 EP 번호 × 11.
- `python3 tools/cards.py ... out.mp4`. /tmp/law_<ep>/ PNG 를 직접 열어 확인한다.
- 캡션: 한 줄 훅 + ✔ 요점 4~5줄 + 공유 유도 + "📚 근거: ..." + "※ 일반적인 법률 정보이며 개별 사안에 대한 법률 자문이 아닙니다. 구체적인 사안은 변호사 또는 대한법률구조공단(132)에 상담하세요." + 해시태그 7개(#법블레스유 #생활법률 고정, 나머지 주제에 맞게).

## 대기열
- `lawbless/queue/<YYYY-MM-DD>/a/`, `/b/` 에 reel.mp4, caption.txt, meta.json({"ep":N,"title":"...","posted":false,"media_id":null}), sources.txt(연 자료 링크).
- EP 번호는 used.txt 가장 큰 번호 다음부터. used.txt 에 `EP.NN 주제(근거) 날짜` 추가.
- 7일보다 오래된 queue 날짜 폴더는 git rm. lawbless/ 밖은 건드리지 않는다.
