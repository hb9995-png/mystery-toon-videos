# 예비부부툰 (@yebibubu.toon) 제작 가이드

하루 2편(점심 a, 저녁 b). 각 편은 1080x1350 컷 7~10장을 그린 뒤, 오리지널 배경음악을 입힌 1080x1920 릴스 영상으로 만든다(2026-11-09 사용자가 캐러셀에서 릴스로 바꾸기로 함). 강아지 커플이 결혼 준비하며 겪는 이야기.
계정 톤은 따뜻하고 웃긴 공감툰이다. 누군가를 비하하지 않고, 마지막에는 실제로 도움이 되는 정리를 준다.

## 1. 도구
- `kit.py`: `from kit import *` 로 쓴다. 들어 있는 것:
  - `T(x, y, 글, 크기, 'g'|'j', 색, anchor)`: 글자. 'g'는 손글씨(감자꽃), 'j'는 굵은 제목(주아).
  - `bubble(x, y, w, 글, 크기, tail=(꼬리x, 꼬리y))`: 말풍선.
  - `header(번호, 총장수)`, `panel(안쪽svg, 배경색, y0, y1)`, `caption(글)`: 컷 칸과 아래 해설 칸.
  - `table`, `lattice`(창호), `hearts`, `sweat`(땀), `speed`(집중선).
  - `render(pages, 출력폴더)`: `{번호: svg}` 를 01.png/01.jpg … 로 만든다. google-chrome 이 필요하다.
- `dogs.py`: `char(kind, x, y, 크기, mood, arms=(왼팔, 오른팔), flip=False)`.
  - kind: `groom`(시바, 신랑, 남색 정장), `bride`(말티푸, 신부, 드레스와 티아라), `momB`(신랑 엄마, 갈색 푸들, 분홍 블라우스), `momG`(신부 엄마, 코기, 라벤더 카디건, 안경), `dadB`(신랑 아빠, 비글, 니트 조끼), `dadG`(신부 아빠, 흑백 강아지, 초록 스웨터, 안경).
  - mood: `happy`, `joy`, `smug`, `shock`, `blank`, `nervous`.
  - 팔 각도는 -40~150 정도. 크기 1.0 ≈ 키 400px.
- 새 조연(친구, 플래너, 직원 등)이나 소품, 배경이 필요하면 `dogs.py` 를 고치지 말고 `tools/extra.py` 에 함수로 추가한다(있으면 이어서 쓴다). 기존 머리 함수(shiba_head, poodle_head, corgi_head, beagle_head, bw_head)에 색만 바꿔 재사용해도 된다. 기존 6명의 생김새와 옷은 바꾸지 않는다.
- 소품: `extra.py` 에 tears(눈물), phone, paper(견적서·명단), chandelier, notebook, chicken_box, vs_badge, page_bg 가 있다. 쓰려면 에피소드에서 `from extra import *`.
- 기준 예시는 `episodes/ep01.py`(썰툰), `ep02.py`(밸런스 게임), `ep03.py`(공감 짤) 다. 새 편은 `episodes/epNN.py`(다음 번호)로 쓰고, 이미 있는 번호는 덮어쓰지 않는다.

## 2. 주제는 매일 다르게
`used.txt` 를 읽고 최근 7편과 같은 주제나 같은 형식이 이어지지 않게 고른다. 결혼 준비의 여러 방면을 돌아가며 다룬다.
- 만남과 결심: 프로포즈, 결혼 결심한 순간, 부모님께 처음 인사, 상견례
- 돈: 결혼 비용 나누기, 예단·예물, 축의금, 신혼집 마련(전세·매매·대출), 혼수 가전, 통장 합치기
- 식 준비: 웨딩홀 투어, 스드메(스튜디오·드레스·메이크업), 청첩장 모임, 하객 명단, 본식 당일 사고, 사회·축가 부탁
- 사람 사이: 양가 부모님 의견 차이, 친구 결혼식 축의금 고민, 명절 어디부터 갈지, 예비 시댁·처가 호칭
- 둘 사이: 결혼 준비하다 싸운 일, 취향 차이(인테리어, 신혼여행지), 서로 감동한 순간
- 신혼여행과 그 뒤: 신혼여행지 고르기, 혼인신고 타이밍, 첫 살림, 신혼 첫 명절
형식도 돌아가며 쓴다(최근 2편과 같은 형식은 피하고, 같은 날 두 편은 주제 분야와 형식을 서로 다르게 한다).
- A 썰툰: 9장 이야기 + 마지막 앞 장에 짧은 정리(ep01 과 같은 구조)
- B 체크리스트: 표지 + 상황 컷 2장 + 항목 카드 4~5장 + 마무리
- C 밸런스 게임·투표: "너라면?" 두 선택지 컷 여러 개, 댓글로 고르게 하기
- D 공감 짤 모음: "결혼 준비하면 생기는 일" 한 장에 한 장면씩 7~8장
- E 대화 썰: 신랑·신부 카톡 화면(ep01 6장처럼) 중심

## 3. 쓰는 법
- 신부(말티푸) 1인칭 반말 일기체가 기본. 가끔 신랑 시점 편도 낸다.
- 표지에 훅 제목 한 줄(15자 안팎) + 분홍 꼬리표 + 아래 띠에 "+ 마지막에 ○○ 정리".
- 해설 칸 글은 두 줄 이내, 줄당 18자 이하. 말풍선도 세 줄 이내. 글자가 칸을 넘으면 줄이거나 크기를 줄인다.
- 마지막 장: 저장·공유 유도, 댓글 질문, `@yebibubu.toon`.
- 정보(비용, 절차, 법)는 일반적인 내용만 쓰고, 숫자나 제도는 그날 실제로 확인한 공식 자료로만 쓴다. 확실하지 않으면 숫자를 빼고 "확인해 보세요"로 쓴다.
- 실존 업체·브랜드·연예인 이름, 특정 지역 비하, 성별 고정관념으로 한쪽을 깎아내리는 농담, 시댁·처가 혐오 표현은 쓰지 않는다. 결말은 둘이 같은 편이 되거나 웃으며 풀리는 쪽으로 한다.

## 4. 확인
렌더링한 뒤 모든 장을 직접 열어 본다(Read 로 이미지 확인). 글자 겹침, 칸 밖으로 나간 글, 잘린 캐릭터, 빈 칸이 없어야 한다. 고친 뒤 다시 렌더링한다.

## 4-1. 릴스 만들기
- `python3 tools/episodes/epNN.py /tmp/yebi/epNN` 로 컷을 렌더링한 뒤 `python3 tools/reel.py /tmp/yebi/epNN reel.mp4 <EP번호×101>` 로 영상을 만든다(표지 3초, 나머지 4초, 마지막 4.5초. 음악은 bgm.py 가 시드마다 다르게 만든다).
- ffprobe 로 1080x1920 H.264 + AAC 인지 확인하고, 프레임 한두 장을 뽑아 본다.

## 5. 게시글
- 첫 줄: 훅 제목 + 이모지 1~2개. 이어서 2~3줄 요약(결말은 말하지 않는다), 정리 장 안내, 공유·댓글 유도.
- 해시태그 5~7개. `#예비부부툰` 고정, 나머지는 그 편 내용에 맞게 매번 다르게(같은 묶음 반복 금지).

## 6. 대기열과 기록
- `yebibubu/queue/<YYYY-MM-DD>/a/`, `/b/` 에 reel.mp4, caption.txt, meta.json({"ep":N,"title":"...","posted":false,"media_id":null}) 을 넣는다. EP 번호는 used.txt 의 가장 큰 번호 다음부터 a, b 순서.
- `used.txt` 에 `YYYY-MM-DD | epNN | 형식 | 주제 | 제목` 한 줄씩 추가한다.
- 7일보다 오래된 queue 날짜 폴더는 git rm. yebibubu/ 밖은 건드리지 않는다.
